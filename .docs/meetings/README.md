# Meetings

Notes from conversations with design partners, the eTIMS integrator, Safaricom,
and anyone else whose answer the plan depends on.

Naming:

```text
YYYY-MM-DD-{topic}.md
```

Capture decisions, questions, risks and follow-ups. A note here is not the
durable record — copy anything that outlives the meeting into its proper home:

| What came out of it | Where it goes |
|---|---|
| A durable choice | `../DECISIONS.md` |
| A business fact the plan needed | `../DOMAIN.md`, and strike the question from `../QUESTIONS.md` |
| A new unknown | `../QUESTIONS.md`, with the sprint it blocks |
| A new trap | `../RISKS.md`, with a tripwire and a date |
| A file they promised to send | `../FILE_INVENTORY.md` |

The week-1 partner meeting is the highest-value meeting in the project. Name all
four files from `FILE_INVENTORY.md` §1 **in advance** so they actually arrive —
that is R-04's mitigation, and it only works if the ask is specific.
